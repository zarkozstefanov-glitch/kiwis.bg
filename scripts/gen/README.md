# Page generators

The HTML pages are generated by these scripts. Run from `website/`:

    python3 -I scripts/gen/build_index.py scripts/gen index.html
    python3 -I scripts/gen/build_menu.py  scripts/gen menu.html
    python3 -I scripts/gen/build_blog.py  blog
    ./scripts/build.sh

- `pv_lib.py` — shared nav/footer + the podium product viewer markup
- `menu_data.json` — the whole menu (names, descriptions, weights, prices, macros, image keys)
- `head.html` — <head> of the landing page (meta + Restaurant JSON-LD)
- `rv/all.json` — the 49 Google reviews; `rev_html.py` turns them into cards (reviews_snippet.html)
- `cut.py` / `cut2.py` — background removal (rembg; needs a Python 3.12 venv with rembg + scipy)
- `kie.py` / `grade.py` — kie.ai Nano Banana 2 enhancement (key read from ../.env) + transfer of the grading to full-res originals
