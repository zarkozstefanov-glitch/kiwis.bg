# Page generators

The HTML pages are generated by these scripts. Run from `website/`:

    python3 -I scripts/gen/build_index.py scripts/gen index.html
    python3 -I scripts/gen/build_menu.py  scripts/gen menu.html
    python3 -I scripts/gen/build_blog.py  blog
    ./scripts/build.sh

- `pv_lib.py` — shared nav/footer + the podium product viewer markup
- `menu_data.json` — the whole menu (names, descriptions, weights, prices, macros, image keys)
- `head.html` — <head> of the landing page (meta + Restaurant JSON-LD)
- `rv/all.json` — the 49 Google reviews; `rev_html.py` turns them into cards (reviews_snippet.html)
- `cut.py` / `cut2.py` — background removal (rembg; needs a Python 3.12 venv with rembg + scipy)
- `recut.py` — background removal with BiRefNet (`birefnet-general`, much cleaner than the old isnet cut: boxes, plates and eggs stay whole) → `assets-src/cutouts/`
- `normalize.py` — frames every cut-out the same way (tight crop, longest side 94%, cups/cans 84% tall, same baseline) from `assets-src/cutouts/*.png` into `images/cut/` — run it after adding or changing a cut-out
- `sauce.py` — recolours the dip cup in a portion cut-out to the menu's sauce (the shoot used one orange sauce for several bowls): beef = cheddar (yellow), chicken = cottage cream (white), turkey = herb skyr, veg = herb skyr. Originals before recolouring/reassigning are in `assets-src/cutouts-orig/`.
- Photo map (Nov 2026 menu): pork brioche = DSCF8682 (box) + DSCF8698 (from above); pulled-pork brioche = DSCF8743 + 8747; pulled-pork bowl = DSCF8792; pork and turkey bowls have no own photo and reuse DSCF8796 (chicken bowl) with their own sauce colour.
- `kie.py` / `grade.py` — kie.ai Nano Banana 2 enhancement (key read from ../.env) + transfer of the grading to full-res originals

## Newsletter backend (PHP 8.4 on SuperHosting)
- `api/subscribe.php` → `api/confirm.php` (double opt-in) → `api/unsubscribe.php` (deletes the person); shared code in `api/_lib.php`
- Data: SQLite + key in `/home/<account>/kiwis-private/` (outside public_html, created on first use). Names and emails are encrypted (libsodium); duplicates found via a keyed hash. **Back up `key.bin` — without it the data can't be read.**
- `admin/` — only from the IPs in `KIWIS_ADMIN_IPS` (api/_lib.php); first visit sets the admin email, then login is a one-time link sent to it. Company details for `privacy.php` are set there.
- `privacy.php` is generated by `build_privacy.py`; the banner `js/join.js` by `build_join.py` (kiwi drawing taken from js/preloader.js)
- Images: `avif.py` writes `*.avif` next to every photo; `.htaccess` serves them to browsers that accept AVIF.
